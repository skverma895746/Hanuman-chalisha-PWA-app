# श्री हनुमान चालीसा एवं सम्पूर्ण स्तोत्र संग्रह (PWA)
### Shri Hanuman Chalisa Text & Audio Player Progressive Web App

सम्पूर्ण शुद्ध देवनागरी पाठ, कराओके-शैली ऑडियो प्लेयर, डिजिटल जप माला एवं ऑफ़लाइन PWA क्षमता से युक्त एक दिव्य भक्ति वेब एप्लिकेशन।

🌐 **लाइव वेब ऐप (Live URL):** [https://skverma895746.github.io/Hunuman-chalisha-PWA-app/](https://skverma895746.github.io/Hunuman-chalisha-PWA-app/)

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **सम्पूर्ण श्री हनुमान भक्ति संग्रह (Complete Devotional Texts):**
   - **श्री हनुमान चालीसा:** २ आरंभिक दोहे, ४० चौपाइयाँ एवं १ समापन दोहा (प्रत्येक चौपाई का सरल हिंदी भावार्थ सहित)।
   - **श्री बजरंग बाण:** संपूर्ण शक्तिशाली संकट निवारक पाठ दोहा व छंद सहित।
   - **संकटमोचन हनुमानाष्टक:** समस्त ८ छंद व संकटमोचन दोहा।
   - **श्री हनुमान जी की आरती:** "आरती कीजै हनुमान लला की..." (पावन दीप आरती)।
   - **श्री हनुमान १०८ नामावली:** अष्टोत्तर शतनामावली मंत्र जप हेतु।
   - **डिजिटल जप माला (१०८ मनके):** स्क्रीन स्पर्श करने पर मंदिर की पीतल की घंटी (Temple Bell Chime) व कंपन (Haptic Feedback) सहित डिजिटल काउंटर।

2. **उन्नत ऑडियो प्लेयर प्रणाली (Advanced Audio Player Engine):**
   - **HTML5 Native Audio API:** 100% शुद्ध जावास्क्रिप्ट, बिना किसी बाहरी लाइब्रेरी के।
   - **कराओके सिंक हाइलाइट (Karaoke Sync Highlighting):** ऑडियो बजते समय वर्तमान चौपाई स्वर्णिम आभा के साथ हाइलाइट होती है और स्क्रीन अपने आप अगली चौपाई पर स्क्रॉल होती है।
   - **ऑटो-स्क्रॉल ऑन/ऑफ टॉगल:** अपनी सुविधा अनुसार चालू या बंद रखें।
   - **कस्टम ऑडियो सपोर्ट:** उपयोगकर्ता अपने डिवाइस से किसी भी पसंदीदा हनुमान चालीसा MP3 फ़ाइल को एक क्लिक में चला सकते हैं।
   - **प्लेबैक गति (Speed):** 0.75x, 1.0x, 1.25x, 1.5x।
   - **लूप / रिपीट मोड:** निरंतर पाठ सुनने हेतु।
   - **ऑडियो विज़ुअलाइज़र:** भक्ति संगीत बजते समय जीवंत स्पेक्ट्रम बार एनीमेशन।

3. **दिव्य यूआई/यूएक्स (Divine Sacred UI/UX):**
   - **भगवा व स्वर्ण थीम:** मंदिर के गर्भगृह जैसी पवित्रता एवं जलते हुए दीपक का सौम्य प्रभाव।
   - **दिन / रात्रि भक्ति मोड (Light & Dark Mode):** रात में पाठ करते समय आँखों के लिए अत्यंत आरामदायक।
   - **व्यू मोड्स (View Modes):**
     - *पाठ + ऑडियो मोड:* पढ़ते हुए सुनना।
     - *केवल पाठ मोड (Granth/Pothi):* ऑडियो बार स्वतः छिप जाता है।
     - *केवल श्रवण मोड:* ध्यानपूर्वक केवल सुनने हेतु।
   - **फॉन्ट साइज़ नियंत्रक (A- / A+):** अपनी सुविधानुसार अक्षरों का आकार छोटा या बड़ा करें।
   - **बुकमार्क सुविधा:** किसी भी चौपाई को स्टार '★' करके सुरक्षित रखें।
   - **कॉपी एवं शेयर:** एक क्लिक में चौपाई कॉपी करें या सीधे व्हाट्सएप पर शेयर करें।
   - **रीडिंग प्रोग्रेस बार:** स्क्रीन के शीर्ष पर पाठ की वास्तविक प्रगति।

4. **100% ऑफ़लाइन क्षमता (Progressive Web App - PWA):**
   - **Service Worker (`sw.js`) & Cache API:** पहली बार खुलने के बाद इंटरनेट/डेटा पूरी तरह बंद होने पर भी ऐप 1 मिलीसेकंड में खुलती है।
   - **Web App Manifest (`manifest.json`):** मोबाइल की होम स्क्रीन पर असली ऐप (Native Android/iOS App) की तरह इंस्टॉल हो जाती है।
   - **₹0 डेटाबेस / 100% प्राइवेसी:** किसी भी बाहरी सर्वर या डेटाबेस की आवश्यकता नहीं।

## 🚀 कैसे चलाएं (How to Run)

### विधि १: सीधे ब्राउज़र में खोलें (Direct Browser)
- `index.html` फ़ाइल पर डबल क्लिक करें। यह किसी भी आधुनिक ब्राउज़र (Chrome, Edge, Safari, Firefox) में तुरंत खुल जाएगी।

### विधि २: लोकल वेब सर्वर (Local Server - PWA टेस्टिंग हेतु अनुशंसित)
सर्विस वर्कर और PWA फीचर्स के पूर्ण परीक्षण हेतु लोकल सर्वर चलाएं:

**Python द्वारा:**
```bash
python -m http.server 8080
```
ब्राउज़र में खोलें: `http://localhost:8080`

**Node.js (npx) द्वारा:**
```bash
npx serve .
```

## 📱 मोबाइल पर ऐप के रूप में कैसे इंस्टॉल करें (Install as App)

### Android (Google Chrome):
1. ब्राउज़र में ऐप का लिंक खोलें।
2. ऊपर दाईं ओर 3-डॉट्स (⋮) मेनू पर क्लिक करें।
3. **"Install app"** या **"Add to Home screen"** (होम स्क्रीन में जोड़ें) चुनें।
4. आपके फोन की होम स्क्रीन पर श्री हनुमान जी के दिव्य आइकन के साथ ऐप इंस्टॉल हो जाएगी।

### iOS / iPhone / iPad (Safari):
1. Safari ब्राउज़र में ऐप खोलें।
2. नीचे दिए गए **शेयर बटन (Share)** पर टैप करें।
3. नीचे स्क्रॉल करके **"Add to Home Screen"** चुनें।
